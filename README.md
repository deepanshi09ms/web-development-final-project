# Machine Learning Lab Website — South Asian University

A four-page responsive website built with HTML5, CSS3 and beginner-friendly JavaScript.

## Pages
- `index.html` — Home
- `pages/about.html` — About the lab
- `pages/services.html` — Services and filterable project gallery
- `pages/contact.html` — Contact form demonstration

## Folder structure
```
project/
├── index.html
├── pages/
│   ├── about.html
│   ├── services.html
│   └── contact.html
├── css/
│   └── style.css
└── js/
    └── script.js
```

## JavaScript features
1. **Theme switcher:** toggles light/dark mode and remembers the choice with `localStorage`.
2. **Mobile menu:** opens and closes the navigation on small screens.
3. **Project filter:** shows projects by category using `data-category`.
4. **Contact form:** checks the fields, counts message characters and displays a front-end confirmation.
5. **Footer year:** automatically displays the current year.

## How to run
Open `index.html` in a browser. No framework, package installation or server is required.

## Important note about the form
The contact form is a front-end demonstration only. It validates the information and displays a confirmation in the browser; it does not send or store messages because this project has no backend/database.

## For the lab walkthrough
- HTML creates the page structure and content.
- CSS controls colours, spacing, layout and responsive design.
- JavaScript adds behaviour through event listeners and DOM updates.


## South Asian University identity
The header uses the South Asian University logo served from the University's official media assets (`https://sau.int/wp-content/themes/sau/images/sau_logo.gif`). The design uses an SAU-inspired blue palette and links back to the official university website. An accessible text fallback appears if the hosted logo cannot load.

This is a student-developed academic microsite and is not the official SAU website. University contact/address information is presented as general university information, not as a direct lab contact.
